# 个人在线简历网页
> 在线简历：https://xxx.pages.dev
> 一份可直接通过公网链接访问的静态HTML简历，面向GIS三维可视化、AI Agent全栈开发求职。

## ✨ 项目特性
- 纯静态前端页面，无后端服务，部署在 Cloudflare Pages
- 样式内嵌在 index.html，无需独立CSS文件；响应式布局，适配 PC / 手机端，处理长文本自动换行，解决移动端文本溢出问题
- 简历数据与页面渲染分离：项目经历、技能、个人信息统一维护在 `resume_data.js`
- 简历包含4个GIS项目：网格化管理平台、火灾应急三维GIS平台、土地违规监管GIS平台、马铃薯冻害数字化管理系统
- 支持自定义修改个人信息、项目描述、技术栈，修改后重新部署即可更新在线简历

## 📁 项目目录结构
.
├── index.html        # 简历主页面（样式内嵌于此）
├── resume_data.js    # 简历数据源（所有项目、技能信息在这里维护）
└── README.md         # 项目说明文档

## ☁️ Cloudflare Pages 部署步骤

1. 将代码推送至 Gitee/GitHub 仓库
2. 登录 Cloudflare 控制台 → Pages → 创建应用 → 连接 Git 仓库
3. 配置构建参数：
   - 构建命令：（静态页面，**留空不需要构建命令**）
   - 构建输出目录：`.` （根目录）
4. 保存并部署，首次部署完成后得到 `xxx.pages.dev` 公网访问地址
5. 后续更新：`git push` 推送代码，Cloudflare Pages 自动触发重新部署

## 📝 修改简历内容

所有简历的项目、个人信息，**只需要修改 `resume_data.js`**

- 修改项目简介、前后端经历、技术栈
- 调整项目顺序，新增 / 删除项目

> 
> 修改完成后本地打开 index.html 校验效果，再提交推送代码。

## 📌 部署说明

- 静态资源托管：Cloudflare Pages，全球 CDN 加速，访问速度快
- 无需服务器，无运维成本，每次 git 自动 CI/CD
- 支持自定义域名（可选）

## ⚠️ 注意事项

1. 简历内容涉及个人项目，仓库建议设置为**私有仓库**，避免个人信息泄露
2. 修改代码提交规范：
   - `feat: xxx` 新增简历内容、新增项目
   - `fix: xxx` 修复页面样式、移动端 bug
3. 移动端修改务必手机浏览器打开预览，检查文本溢出、换行效果
